## 👨‍💻 Sobre Mí

¡Hola! Soy **Matías Bazán**, Desarrollador Full Stack especializado en **Flutter**, **Node.js** y **PostgreSQL**. Me enfoco en crear soluciones de software sólidas, eficientes y bien estructuradas tanto para plataformas web como móviles.

Actualmente me encuentro investigando y aplicando **Spec Kit SDD (Spec Driven Development)** para optimizar el diseño de especificaciones, arquitecturas y desarrollo guiado por requerimientos.

- 📍 **Ubicación:** Argentina
- 🔬 **En exploración / aprendizaje:** Spec Kit SDD (Spec Driven Development)
- 🎯 **Objetivo:** Construir productos digitales escalables con código limpio y arquitecturas robustas.
